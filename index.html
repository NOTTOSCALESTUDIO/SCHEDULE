Out-of-sync parts

Parts that roll in apart from their parent fuselage, usually the first half of Friday. Most go through prep, prime and final sand at other stations first, so paint sees them end of day or next morning. Then: full base and clear from primed, sealer first if there are burns. They go in whichever painter session they fit: the cart's booth run if obsidian, otherwise the next repair session.

    Repair turnaround

    Flaws found by, or created at, nearby stations. The clock starts when we begin working the part: triage for other issues, preps it (plus body work if needed), and only then can it go in a session. The painter runs scheduled repair sessions; each repair goes in the first session it can be prepped for, or rides the cart's base/clear load if that's sooner. Bars show shift hours from starting work to back in hand. Target: 6 hours for repairs started by 14:00; later ones are expected the next morning.
